## Customer presentation changes

- Selected-case, expected and finite global-bound return rates share the denominator `E + max(premium + option fees, 0)`. Borrowed funds are excluded; all configured costs remain in PNL. Infinite bounds have no finite yield percentage.
- Tail protection sizing keeps the current protective-leg mix. OTC notionals are scaled to a zero adverse-tail slope (100%). CME notionals are scaled and rounded up by leg to 125,000 CHF lots for the minimum in that proportional mix that reaches at least 100%.
- The sizing control reprices the entire current model so premiums, fees, outcomes, probabilities and global bounds update together. It does not include execution costs for closing any existing real position.
- The PNL and probability chart displays its dynamic exchange-rate axis and relative movement from S0. Probability outside the chart range remains visible as left/right tail mass; event probabilities and expectations use the full positive-rate domain.
- PNL=0 and PNL=PNL_origin equality probabilities are collapsed by default. Historical exact-threshold equality remains strict and is also hidden by default.
- Workbook summary, model, all historical windows and bootstrap paths now share the same denominator in formulas, cached values and labels. Finite global-bound yields are appended without moving existing formula addresses; infinite bounds remain text.
- Rebuilding capital, FX start or horizon clears prior tail-quantity overrides. Existing forward overcoverage removes unnecessary CME protective purchases instead of attempting a negative quantity.
- `pnpm start` uses `scripts/start-preview.mjs` to select the checkout's ignored `.dev.vars` by absolute path; credentials are never copied into source or build output.
- Previous Q&A is retained at `docs/CHF-Collar-Lab-V5.2.0-QA.docx` for source-repository handoff.
